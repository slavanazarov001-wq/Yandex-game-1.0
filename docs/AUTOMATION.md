# Что уже сделано автоматически

На вашем ПК в рамках настройки репозитория выполнено:

1. **Установка GDevelop** через `winget` (пакет `GDevelop.GDevelop`, текущая версия из каталога winget).
2. **Проверка запуска**: редактор открывается с файлом проекта, если передать путь к `Yandex-game-1.0.json` первым аргументом (как делает скрипт ниже).

Повторная установка обычно не нужна. Обновление редактора: `winget upgrade GDevelop.GDevelop`.

## Открыть игру одним действием

Дважды щёлкните:

`scripts/Open-Yandex-game-project.bat`

или в PowerShell из корня репозитория:

```powershell
.\scripts\Open-Yandex-game-project.ps1
```

Скрипт сам находит `GDevelop.exe` в стандартных путях и открывает `gdevelop/YandexStarter/Yandex-game-1.0.json`.

## Что нельзя убрать полностью

- Первый запрос **UAC / winget** при установке софта на вашей машине может потребовать подтверждения системой Windows — это ограничение ОС, не репозитория.
- Работа внутри **окна GDevelop** (события, экспорт) всё равно идёт в графическом редакторе; автоматизировать «создание геймплея без вашего участия» нельзя без отдельного задания на разработку в этом репозитории.
