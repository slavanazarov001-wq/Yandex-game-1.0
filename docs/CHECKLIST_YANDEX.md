# Чеклист перед отправкой на модерацию (Яндекс Игры)

Краткая памятка; полный текст — в [требованиях](https://yandex.ru/dev/games/doc/ru/concepts/requirements).

## SDK и билд

- [ ] В билде подключён **SDK Яндекс Игр** (через расширение GDevelop); реклама и платежи **только** через SDK.
- [ ] Когда игрок может играть, вызывается готовность игры (**Game Ready** / `LoadingAPI.ready()` согласно документации и вашей реализации в событиях).
- [ ] При полноэкранной рекламе — **пауза** звука и геймплея; реклама в **логических паузах**, не мешает управлению.
- [ ] Архив: в корне **`index.html`**, распакованный размер **≤ 100 МБ**, в путях **нет пробелов и кириллицы**.

## Поведение и стабильность

- [ ] Нет зависаний, «сырых» ошибок, технических сообщений в UI при типовых действиях (поворот, реклама, сворачивание).
- [ ] При сворачивании вкладки/приложения **звук останавливается**.
- [ ] Интерфейс не обрезается; для мобильных учтены жесты / полноэкран / ориентация по черновику.

## Черновик и языки

- [ ] **Название** игры в приложении и во всех материалах черновика **совпадает** на каждом заявленном языке.
- [ ] Все значимые для геймплея тексты переведены на заявленные языки; язык UI соответствует выбранному языку игры.

## Монетизация

- [ ] Реклама подключена по правилам РСЯ / Консоли; rewarded — понятная кнопка и награда, без блокировки основного прохождения только рекламой.

## Контент

- [ ] Возрастной тег соответствует содержанию; нет запрещённого контента по разделу 3 и 8 требований.
